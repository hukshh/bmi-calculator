# BMI Calculator

A modern, responsive Body Mass Index (BMI) calculator built with React and Vite. This application helps users calculate and track their BMI with an intuitive interface and comprehensive health information.


## Features

- **BMI Calculator**
  - Metric and Imperial unit support
  - Real-time BMI calculation
  - Visual BMI category indication

- **User Profile Management**
  - Personal information storage
  - Health goals tracking
  - Progress monitoring

- **BMI Information**
  - Comprehensive BMI category guide
  - Health recommendations
  - BMI limitations explanation

- **Interactive Dashboard**
  - BMI history tracking
  - Progress visualization
  - Health tips and recommendations

## Technologies Used

- React 18
- Vite
- CSS Modules
- Chart.js
- React Router DOM

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/hukshh/bmi-calculator.git
cd bmi-calculator
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit:
```
http://localhost:5173
```

## Usage

1. Create your profile with basic information
2. Select your preferred unit system (Metric/Imperial)
3. Enter your height and weight
4. Get instant BMI calculation with category
5. Track your BMI history over time
6. View health recommendations based on your BMI

## BMI Categories

- Underweight: < 18.5
- Normal Weight: 18.5 - 24.9
- Overweight: 25.0 - 29.9
- Obese: ≥ 30.0
